嗯...🤔 如果放入更多的声音的话呢？

<MiniRepl client:visible tune={`sound("bd hh sd hh bd hh sd crow bd hh sd oh bd hh crow crow")`} />

我们会发现pattern的运行变得更快、更密集了。这是因为 Strudel 在后台有一个固定时间的“循环”。pattern中的任何声音都将在一个周期内运行，strudel 也会尝试均匀地分布这些声音。

因此“咚次哒次”的速度会...
<MiniRepl client:visible tune={`sound("bd hh sd hh")`} />
比“咚次哒次咚咚哒次”来得慢。
<MiniRepl client:visible tune={`sound("bd hh sd hh bd bd sd hh")`} />

另外，strudel中有许多的缩写，比如我们可以用s来代表sound。
<MiniRepl client:visible tune={`s("mt rim lt oh")`} />

现在，让我们来看看如何同时发出多个声音

# 基础语法

Strudel有一套被称为mininotation的非常棒的语法，它可以帮你快速地构建丰富的pattern。
比如我们可以用 * 来加快声音在序列中播放的速度。

<MiniRepl client:visible tune={`sound("hh*4")`} />
<MiniRepl client:visible tune={`sound("hh*8")`} />
<MiniRepl client:visible tune={`sound("hh*16")`} />
<Box>

These are just a few of the available sounds. Each one contains multiple samples that you can access using a colon and number:

```
sound("casio:0")
sound("casio:1")
sound("casio:2")
```

Try mixing different sounds together!

</Box>

## Drum Sounds

Strudel includes a rich collection of drum sounds. Here are the basics:

The letters represent different drum kit components:

- `bd` = bass drum
- `sd` = snare drum
- `hh` = hi-hat
- `oh` = open hat
- `rim` = rimshot
- `tom` = tom

Experiment with different combinations!
