(Yo, if you're on Windows or Linux, this probably won't help you much, cause I've only got a Mac 😭)

So you've create something in Strudel and fancy sticking it on your socials. Bit of a bummer though, cause Strudel doesn't actually have a built-in record or export audio feature at the moment. Anyway, here's a few ways you can get it sorted.

**I've just listed the software below that'll do the job, but there's no specific guide. I might do some video tutorials one day, but for now, you'll have to do a bit of reserach :)**
<br />

# Sample - a chrome extension
https://chromewebstore.google.com/detail/sample/kpkcennohgffjdgaelocingbmkjnpjgc
- **Pros:** free, easy to install

- **Cons:** makes you stuck with Google Chrome, only simple audio editing
<br />
# OBS Studio
https://obsproject.com/
- **Pros:** free and sorts both your audio and screen recording in one go. Also can grab audio just from specific apps.

- **Cons:** the interface can be a bit confusing if you're new to it, and I'm pretty sure you can't only record audio and get a audio file.
<br />
# BlackHole + Any recording software
https://existential.audio/blackhole/

- **Pros:** It's freeeee!

- **Cons:** Setting it up can be a bit of complex, and it records all your system sounds as well.
<br />
# LOOPBACK + Any recording software
https://rogueamoeba.com/loopback/

- **Pros:** You can grab audio just from specific apps. The visual interface makes setting it up super easy.

- **Cons:** It's not free (and kinda expensive)!
